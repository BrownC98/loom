2. URL 복제 — 복제하는 동안 (부모 폴더 칸을 누르면 1의 폴더 목록이 열립니다)

  • loom/home/me/loom

저장소 추가

3. URL 복제 — 실패

저장소

  • loom/home/me/loom

저장소 추가

/home/me/loom/app 폴더가 이미 있고 비어 있지 않습니다. 다른 부모 폴더를 고르십시오. 그 폴더는 건드리지 않았습니다.
