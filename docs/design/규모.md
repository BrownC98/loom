# 규모

- 화면과 그 둘레 한 화면 안의 카드만 터미널 스트림을 연다(「그래프와 화면」). 그 밖의 카드는 상태와 마지막 한 줄만 받는다.
- 노드마다 출력 링 버퍼를 256KB까지 둔다. 카드를 다시 열면 버퍼를 먼저 보내고 실시간 출력을 잇는다.
- 노드와 대기의 주인은 DB 하나다. 노드나 대기가 바뀌면 데몬은 `/api/events`에 내용 없는 `Nodes`를 보낸다. 연결할 때도 먼저 한 번 보낸다. 화면과 휴대폰 앱은 사건으로 사본을 고치지 않고 `GET /api/nodes`로 목록을 다시 읽는다. 읽는 동안 새 `Nodes`가 오면 그 답은 버리고 한 번 더 읽는다. 그래서 마지막 읽기의 답만 그리고, 연결이 끊긴 동안 지운 노드가 남지 않는다. 근거: 감사 17(SC01·SC05). 노드 사본을 사건으로 고치던 화면은 DB와 다른 사실을 하나 더 가졌다.
