loom v0.2.3 · Windows 앱의 데몬
누른 뒤: 앱 창이 뜨고 앱의 진행 카드(다운로드 → 다시 시작)가 보인다. 이 탭은 데몬이 바뀐 뒤 저절로 다시 붙는다.
  • ①과 같은 카드, 같은 [업데이트] 단추다. 사람은 데몬이 어디서 왔는지 고르지 않는다.
  • [업데이트]: 데몬이 옆의 앱을 업데이트 표시와 함께 띄운다. 앱은 묻지 않고 받아 설치하고 다시 뜬다. 새 판이 이기므로 데몬도 바뀐다. 노드는 산다.
  • v1의 「loom 앱 창에서 업데이트합니다」 안내와 [loom 앱 열기] 단추는 지운다.

③ 데스크톱 앱 창 바뀌지 않음

  • 지금 카드 그대로다(Tauri 업데이터). 새 앱이 뜨면 새 판이 이기므로 옛 데몬을 바꾼다. 노드는 산다.
  • 앱 창에는 ①②의 데몬 카드를 띄우지 않는다. 같은 알림이 둘 뜨지 않게 한다. 업데이트 표시로 뜬 앱은 [업데이트]를 다시 묻지 않는다.
  • 사람이 쓰는 개발 빌드(scripts/host.sh)는 Release 판이 아니라 알림을 띄우지 않는다.
