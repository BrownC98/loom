그래프: 저장소 상자에서 새 워크트리 만들기

사람 요청 "그래프에서 저장소 묶음에 새 워크트리 만드는 버튼 추가". 저장소 상자 머리 오른쪽 끝에 [새 워크트리]를 둔다. 누르면 사이드바의 새 워크트리 창과 같은 창이 버튼 아래에 뜬다. 바뀌는 구역은 저장소 상자 머리뿐이다. 점선(노랑)이 바뀌는 곳이다. 그림은 심플 보기를 실제 크기로 그리고 줄였다.

① 저장소 상자 머리의 버튼 저장소가 둘 이상 보일 때

‘새 노드’를 눌러 첫 에이전트를 시작합니다.

  • 순서는 묶음 머리와 같다: [이 저장소 정렬] 아이콘 → [새 워크트리]. 버튼은 오른쪽 끝에 있다.
  • 모양은 묶음 머리의 [새 노드]와 같은 작은 고스트 버튼이다. 아이콘은 사이드바 저장소 줄의 새 워크트리 아이콘(가지+)이다.
  • 머리를 끌면 상자가 움직인다. 버튼을 누를 때는 상자가 움직이지 않는다.

fix/login
main ▾

만들 폴더: ~/loom/workspaces/alpha/login

  • 창의 오른쪽 끝은 버튼 오른쪽 끝에 맞고, 창은 버튼 6px 아래에 뜬다. [새 노드] 창과 같은 규칙이다. 그래프를 확대·축소하면 창도 같이 바뀐다.
  • 칸과 문구는 사이드바의 새 워크트리 창과 같다(브랜치 이름, 기준 브랜치, 만들 폴더, 취소·만들기).
  • [만들기]가 끝나면 창이 닫히고, 새 묶음이 그 저장소 상자 안 빈 자리에 생긴다. 바깥을 누르거나 Esc를 누르면 창이 닫힌다.
