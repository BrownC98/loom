loom 네이티브 데스크톱 창: 그래프 캔버스와 설정

사람 결정(Q1966): 네이티브 창의 가운데는 웹과 같은 그래프 캔버스이고, 설정 창도 네이티브로 그립니다. 질문에 붙은 문서는 기본 브라우저에서 엽니다. 색, 글꼴, 카드, 선, 왼쪽 트리, 질문 줄은 웹 화면과 같습니다. 아래 번호는 v1과 달라진 곳과 아직 정할 곳을 가리킵니다.

  1. 앱 실행: 데몬에 붙음
  2. 그래프에서 카드를 고름
  3. 카드 안 터미널에 바로 입력
  4. 질문은 오른쪽 질문 탭에서 답함
  5. 설정은 앱 안 설정 창에서 바꿈

D9카드의 터미널은 어디에 여는가

A카드 안에 엶(웹 표준 카드와 같음)권장웹: 표준 카드 안 터미널 → 네이티브: 같음 · 비용: 화면에 보이는 카드마다 터미널 하나(웹도 같음) · 되돌리기: 카드 보기를 「심플」로 바꾸면 오른쪽 독에 하나만 엶
B카드는 요약만, 고른 카드의 터미널을 오른쪽 칸 하나에 엶웹 「심플」 보기만 남김 · 비용 작음(터미널 하나) · 여러 노드의 화면을 한눈에 못 봄
  • 사람이 「웹과 같은 그래프」를 골랐습니다(Q1966). 웹 표준 카드가 A입니다.
  • 웹에도 「심플」 보기(B 모양)가 있어서, A로 만들면 두 모양을 다 갖습니다.
  • 네이티브 그리기가 웹보다 나은 곳은 터미널 여럿을 함께 그릴 때입니다.

D11첫 판에서 뒤로 미루는 웹 기능이 있는가(그래프 위 질문 알약, 입력 창, 이벤트·커밋 그래프 탭)

A다음 판으로 미룸권장웹: 그래프 위 알약·입력 창, 독 탭 4개 → 네이티브 첫 판: 질문은 독 질문 탭, 입력은 카드 터미널, 이벤트·커밋 그래프는 브라우저 · 비용 작음 · 되돌리기: 다음 판에 하나씩 더함
B첫 판에 모두 넣음끌어 옮기는 떠 있는 창 2개와 커밋 줄 그림을 더 만듦 · 첫 판이 늦어짐
  • 질문 알약과 독 질문 탭은 같은 질문을 두 곳에 보입니다. 첫 판은 한 곳으로 답할 수 있습니다.
  • 입력 창은 웹 터미널의 한글 입력을 돕습니다. 네이티브 카드 터미널은 한글을 바로 받아야 하고, 첫 시험(스파이크)이 이것을 확인합니다.
