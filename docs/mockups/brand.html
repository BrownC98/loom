서비스 이름 시안

2차 이름 후보 8개(짧고 소리 내기 쉬운 이름), 1차 이름 후보 6개, 이름을 바꿀 때 드는 비용을 보인다. 아이콘은 지금 것을 둔다. 마지막 「결정할 것」 표에서 고른다. 이 페이지는 목업이다. 제품 코드는 바꾸지 않았다.

1. 2차 이름 후보

규칙: 1~2음절, 3~5자, 한국어와 영어 사용자가 모두 쉽게 소리 낸다(어려운 자음 묶음 없음, 들은 대로 적는다). 직물 낱말(weft, skein, heddle)은 뺐다. 조사 방법은 1차와 같고, 2026-10-20에 했다. 상표 등록은 찾지 않았다. 모든 후보의 상표 상태는 가설이다.

2. 1차 이름 후보 (참고)

CLI 이름은 사람과 에이전트가 <이름> spawn …처럼 매번 친다. 짧을수록 좋다. 충돌 조사는 2026-10-20에 직접 했다. 출처와 방법은 표 아래에 있다.

이름뜻 · 맞는 이유읽기CLIcrates.ionpmwingetGitHub 별 상위개발 도구 웹 검색판정
loom현재베틀 날실·씨실을 엮는 베틀. 에이전트 여럿을 한 그래프로 엮는다. 룸 / loom loom spawn (4자) loom 7,299만 내려받기 (tokio-rs 동시성 테스트) loom 있음 (생성기 도구) Loom.Loom(Atlassian)과 Teradata.Loom이 별칭 loom을 쓴다 CapSoftware/Cap ★23k(Loom 대체품), tokio-rs/loom ★2.8k Atlassian Loom(loom.com 영상 메시지)이 검색 첫 화면을 차지한다. 등록 상표 여부는 가설: 확인하지 않음 충돌 큼

  • 발견: 직물 낱말(weft, skein, heddle)은 2026년 AI 에이전트 도구가 이미 많이 쓴다. heddle도 에이전트 터미널·오케스트레이터가 셋 이상 있어 표에서 뺐다. 그래서 직물 비유를 바로 쓰지 않는 Kumi를 권장한다.
  • crates.io: curl https://crates.io/api/v1/crates/<이름>. npm: npm view <이름>. GitHub: gh search repos <이름> --sort stars -L 3.
  • winget: winget 공식 색인(cdn.winget.microsoft.com/cache/source2.msix의 index.db)에서 id·이름·별칭·명령을 찾았다. 우리 BrownC98.loom은 아직 이 색인에 없다. 첫 등록 PR이 열려 있다(4절 표).
  • 웹 검색: “<이름> AI agent developer tool”로 찾았다. 상표 등록(KIPRIS, USPTO)은 찾지 않았다. 모든 후보의 상표 상태는 가설이다.
  • Kumi의 약점: 한국어 사용자에게 뜻이 바로 보이지 않는다. 일본어 낱말이다.

4. 이름을 바꿀 때 바뀌는 곳

저장소에서 loom을 쓰는 곳은 48개 파일, 397줄이다(git grep -i loom, 목업 제외). 아래 표에서 「둔다」는 낮은 비용 안(표시 이름만 바꾸기)에서 바꾸지 않는 곳이다.
