승인할 것

정할 것권장사람이 보는 것(지금 → 바꾼 뒤)비용·준비위험 · 되돌리기
알림 방식A. 폰이 직접 확인: Android 작업 예약(JobScheduler)으로 6시간마다 GitHub latest.json을 보고 폰 안에서 알림을 냅니다앱을 열어야 띠 → 앱을 닫아도 6시간 안에 알림(추정: 절전 모드면 더 늦음)계정·키 없음. 6시간에 요청 1번(작은 JSON). 새 라이브러리 없음새 판이 나온 뒤 몇 시간 늦게 알 수 있음. 되돌리기: 커밋 되돌리기
B. Firebase(FCM)릴리스 몇 분 뒤 알림Firebase 프로젝트, google-services.json, release.yml에 서버 키 비밀값키 관리, Google Play 서비스가 없는 폰에서 안 옴. 버리는 이유: 몇 시간 차이에 비해 준비와 키가 큽니다
C. PC 데몬 연결로 보냄PC가 켜져 있을 때만 알림앱이 늘 연결을 잡는 전경 서비스, 상단에 늘 아이콘배터리 소모, 새 판은 PC가 아니라 GitHub에서 옴. 버리는 이유: 비용이 크고 PC가 꺼지면 안 옴
D. 지금 그대로앱을 열 때만 띠없음사람 요청을 채우지 못함
켜기·끄기 자리②의 설정 판(테마와 함께)위 막대 테마 단추 → 설정 단추, 판에 테마와 알림단추 하나 그대로다른 안: Android 앱 알림 설정에만 둠(앱 안 스위치 없음). 버리는 이유: 사람이 앱 안 옵션을 요청함
기본값켬, 처음 열 때 한 번 허용을 묻습니다(③)업데이트 뒤 첫 실행에 Android 허용 창 한 번없음다른 안: 끔으로 시작. 버리는 이유: 사람이 켜기 전까지 지금과 같음
켰을 때 앱 안 띠새 판 띠는 보이지 않고 알림만 냅니다. 받는 중·설치 띠는 그대로입니다앱을 열면 띠 → 알림판에 알림없음다른 안: 띠와 알림을 함께. 버리는 이유: 같은 알림이 두 번 보입니다
