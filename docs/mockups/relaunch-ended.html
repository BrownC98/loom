끝난 노드도 「⋯」 메뉴에서 다시 띄우기

사람 결정(Q1308 답 A): 목업을 먼저 본다. 지금은 종료된 노드(종료·설정 실패)를 같은 대화로 되살리는 길이 loom relaunch 명령뿐이다. 메뉴의 「다시 띄우기」는 실행 중·완료 노드에만 보인다. 바꾼 뒤에는 끝난 노드의 메뉴에도 같은 항목이 보이고, 누르면 같은 번호·이름·부모·자식으로 다시 뜬다. 점선 상자가 새로 보이는 곳이다.

1같은 번호 · 이름 · 부모 · 자식으로 실행 중으로 돌아온다. 「종료(1)」 표시가 사라지고 사이드바 점이 파랑이 된다. 새 노드를 만들지 않는다.
