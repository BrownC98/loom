휴대폰 앱: 질문·완료를 푸시 알림으로

사람 지시: 「앱버전 알림은 푸시 알림으로 구현해줘, on off 옵션 제공할」, 「내가 말한건 업데이트 알림이 아니라, 질문 완료 알림」. 지금 휴대폰 앱은 질문과 완료를 앱 안 알림 탭에서만 보입니다. 앱이 닫혀 있으면 알 수 없습니다(PC 화면의 시스템 알림은 휴대폰 앱에서 동작하지 않습니다). 바꾼 뒤에는 앱을 닫아 두어도 새 질문과 완료가 Android 알림으로 바로 옵니다. 업데이트 띠는 지금 그대로입니다. 점선이 새 것입니다.

승인할 것

정할 것안사람이 보는 것(지금 → 바꾼 뒤)비용·준비PC가 꺼지면 · 위험 · 되돌리기
보내는 방식A. 앱이 PC에 늘 연결(권장): Android 전경 서비스가 지금 앱과 같은 길(같은 Wi‑Fi 또는 Tailscale)로 PC loom에 연결을 잡고, 새 질문·완료를 받아 알림을 냅니다앱을 열어야 봄 → 몇 초 안에 알림. 알림판에 연결 표시 하나(①-3)계정·키 없음. 배터리: 연결 하나를 잡아 둠(추정: 하루 몇 % 이하, 기기 시험으로 잼). 새 Android 권한(알림, 전경 서비스)PC가 꺼지거나 닿지 않으면 연결 표시가 「PC에 닿지 않음」이 되고 다시 시도합니다. 그동안 알림 없음. 되돌리기: 스위치 끄기, 커밋 되돌리기
B. Firebase 푸시(FCM)몇 초 안에 알림. 연결 표시 없음Firebase 프로젝트와 APK 설정 파일, 각 PC loom에 서버 키. 질문 글이 Google 서버를 지남PC가 꺼지면 질문도 생기지 않음(같음). 버리는 이유: 키를 모든 PC에 나눠야 하고 Google Play 서비스가 없는 폰에서 안 옴
C. 15분마다 확인(WorkManager)15분에서 절전 때 몇 시간 늦게 알림계정·키 없음. 배터리 가장 적음버리는 이유: 질문은 몇 분 안에 알아야 함
D. 지금 그대로앱을 열어야 봄없음사람 요청을 채우지 못함
켜기·끄기③ 설정 판에 질문·완료 스위치 2개테마 단추 → 설정 단추, 판에 테마와 알림단추 수 그대로다른 안: 스위치 1개(둘을 함께). 버리는 이유: 완료는 많고 질문은 급해 따로 끄고 싶을 수 있음
기본값둘 다 켬, 처음 열 때 한 번 허용을 묻습니다(④)업데이트 뒤 첫 실행에 Android 허용 창 한 번없음다른 안: 끔으로 시작(PC 화면 「시스템 알림」 기본과 같음). 버리는 이유: 휴대폰은 앱을 닫아 두는 때가 많음
앱을 보고 있을 때Android 알림을 내지 않습니다. 앱 안 알림 탭과 질문 띠만 보입니다지금과 같음없음다른 안: 늘 알림. 버리는 이유: 같은 것이 두 번 보임

PC 화면의 웹 푸시(WebPush)는 쓰지 않습니다. 휴대폰 앱의 화면(Android WebView)이 웹 알림과 웹 푸시를 지원하지 않습니다.
