  • impeccable detect 1회: 결함 4건을 고쳤다(카드 테두리+넓은 그림자, 프로필 선택 칸 좌우 여백, 제목 크기 단계 1.14배→1.29배, h1 다음 h3). 오탐 1건: .app 아래 테두리 여백 경고. 화면 틀의 테두리이고 안쪽 패널이 여백을 가진다.
  • WIG: 고쳤다 — theme-color, 코드·경로·브랜치에 translate="no", 카드 이름 말줄임, 카드 키보드 포커스(tabindex). 구현 때 지킨다 — 상태 변화 aria-live="polite", 간선 강조 효과의 prefers-reduced-motion, 숫자 Intl. 적용하지 않았다 — 영어 문구 규칙(한국어 UI 예외), [워크트리 닫기] 확인 창(브랜치가 남아 다시 만들 수 있고, 미커밋 변경과 running 노드가 있으면 거부한다).
  • better-interface: 하위 스킬 6개를 따로 불러오지 않고, 캡처와 소스로 6개 영역을 한 번에 봤다. 상위 문제 2건 — 확대 상태에서 돌아가는 길이 없었다([축소] 추가), 터미널 안에서 키보드로 빠져나올 길이 없다(위 「정할 것」).
  • 명도 대비(OKLCH 명도로 계산): 보조 글자 --ink-3 대 바탕 6.6:1, 대 카드 머리 5.7:1. 강조색 위 글자 7.2:1. 모두 4.5:1 이상이다.
