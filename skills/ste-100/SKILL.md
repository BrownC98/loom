# STE-100

모든 글에 ASD-STE100(Issue 9)을 적용한다.

- 사람에게 보이는 글은 사람의 언어로 쓴다. 사람의 언어는 사람이 나에게 쓰는 언어다. 사람의 글이 아직 없으면 지시 파일과 저장소 문서의 언어를 쓴다. 대상은 보고, 진행 안내, 문서, 지시 파일, 이슈·MR·커밋 본문, UI 문구다.
- 에이전트끼리 주고받는 글은 영어로 쓴다. 대상은 브리프, 에이전트 메시지(loom `send`·`reply`·`done`, Orca `ask`·`reply` 등), 하위 에이전트 지시, 에이전트 메일이다.
- 코드·명령·경로·식별자·화면 글자·사람이 쓴 원문 인용은 원래 형태로 둔다.

사람의 언어가 한국어면 영어 고유 규칙을 이렇게 바꾼다.

- 관사 → 조사를 생략하지 않는다.
- -ing 금지 → 명사화(진행하다, -함, -기) 대신 동사를 쓴다.
- 단순 시제 → 추측 종결(-ㄹ 것 같다, -로 보인다)을 쓰지 않는다. 확인하지 않은 내용은 "가설:"로 쓴다.
- 단어 수 → 어절 수: 절차 15어절, 설명 18어절 이하.
- 승인 낱말 → 쉬운 말: 실시·수행·진행·처리·활용·기재·해당·상이 대신 하다·쓰다·적다·그·다르다를 쓴다. 번역투(~을 통해, ~에 있어서, ~로 인해)를 쓰지 않는다.

정확한 규칙과 사전은 ASD-STE100 Issue 9 원문 PDF에 있다. 이 스킬 폴더에 `ASD-STE100_ISSUE9.pdf`가 있으면 그 파일을 본다. loom은 이 PDF를 싣지 않는다. 이 PDF의 글을 저장소나 웹 페이지에 옮기지 않는다. ASD가 허가 없는 복제를 금지한다.
