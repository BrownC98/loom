살아 있는 문서: 문서 페이지에서 에이전트와 대화하고, 고친 판을 바로 보고, 다른 문서로 가기

사람 지시: “loom에서 만들어지는 문서는 실시간으로 에이전트와 소통하면서 파일을 수정하거나, 다른 문서로 링크가 연결될 수 있게 해줘”. 지금 문서 페이지는 열린 질문이 있을 때만 답을 한 번 보낼 수 있습니다. 질문이 없으면 보낼 칸이 없고, 에이전트가 파일을 고쳐도 새로 고침을 눌러야 보입니다. 문서끼리 잇는 링크도 없습니다. 바꾼 뒤에는 문서마다 에이전트와 대화하는 칸이 있고, 에이전트가 고친 판이 읽던 자리 그대로 바뀌고, 문서 안의 문서 ID 링크(R303 등)를 누르면 그 문서 페이지로 갑니다. 웹·앱·데스크톱은 모두 같은 문서 페이지를 브라우저에서 열므로 한 번 바꾸면 셋 다 바뀝니다. 빨간 상자가 바뀌는 곳이고, 점선 상자는 새로 생기는 곳입니다.

사람: 문서 페이지에서 말 보내기→loom: 그 문서를 만든 에이전트에게 전달→에이전트: 파일을 고치고 점검을 다시 돌림, 답을 씀→문서 페이지: 새 판과 답을 바로 보임
