웹 버전: 화면에서 loom 끄기

사람 결정: 탭을 닫아도 loom은 계속 돈다. 끄는 버튼은 화면에 둔다. 버튼은 웹 버전에만 보인다. 데스크톱 앱은 창을 닫으면 꺼진다. 점선이 바뀌는 곳이다.
