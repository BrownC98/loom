loom 알림(질문 탭)에서 폴더 신뢰·첫 설정·셸 물음에 바로 답하기

사람 지시: 「내 말은 loom 내부 알림을 말한거임 트러스트 폴더 등의 알림은 직접 터미널에서 입력하게 한걸 알림 ui에서 직접 선택할 수 있게 하라는 뜻이였음」. v1의 Windows 알림 안은 버렸습니다. 승인 요청은 이미 버튼으로 답합니다(M11). 이번에는 터미널에서만 답하던 나머지 창도 같은 꼴로 바꿉니다. 점선이 새로 생기는 곳입니다. 질문 알약을 펼친 목록과 폰 알림 탭도 같은 줄을 씁니다.

노드 터미널에 창이 뜬다→질문 탭에 그 창의 글과 선택지→버튼·입력칸으로 답한다→loom이 그 터미널에 키를 친다

① 지금 폴더 신뢰 줄

이벤트커밋 그래프질문 1
  • 워커 화면 · 폴더 신뢰 확인Claude
    Yes, I trust this folder
1지금은 이 버튼으로 노드 터미널로 간 뒤 키를 직접 칩니다. ②~⑥에서는 이 자리에 터미널 창의 선택지가 나옵니다.

② 폴더 신뢰 · Claude Quick safety check 창

이벤트커밋 그래프질문 1
  • 워커 화면 · 폴더 신뢰 확인Claude
    Quick safety check: Is this a project you created or one you trust? /home/ktadev/loom/workspaces/loom/화면
1터미널 창의 글 아래에 선택지마다 버튼 하나. 누르면 loom이 그 노드 터미널에 그 키를 칩니다. 치기 직전 화면을 다시 읽고 같은 창일 때만 칩니다. 창이 바뀌었으면 키를 치지 않고 빨간 줄로 이유를 보입니다. 승인 요청 줄(M11)과 같은 꼴입니다.

③ 폴더 신뢰 · Cursor Do you trust the contents of this directory?

이벤트커밋 그래프질문 1
  • 워커 검사 · 폴더 신뢰 확인Cursor
    Do you trust the contents of this directory?
1키 칸은 그 창이 쓰는 키입니다(Cursor는 a·q, Codex·Claude는 숫자). Codex의 「Trust this folder?」 창도 같은 꼴입니다.

④ 로그인·첫 설정 선택 로그인·계정 설정

이벤트커밋 그래프질문 1
  • 워커 배포 · 로그인·계정 설정Claude
    Select login method:
1로그인 방식, 글자 스타일 고르기 같은 첫 설정 창도 선택지 버튼을 보입니다. 브라우저 로그인이나 코드 붙여넣기처럼 선택지가 없는 단계는 ①처럼 「터미널에서 답하기」만 보입니다.

⑤ 셸 확인 질문 [y/n]·(yes/no)

이벤트커밋 그래프질문 1
  • 셸 배포 · 입력 요청셸
    Do you want to continue? [y/n]
1셸의 [y/n]·(yes/no) 물음에 버튼 둘. 누르면 그 글자와 Enter를 칩니다.

⑥ 비밀번호·이름 입력 password·passphrase·Username

이벤트커밋 그래프질문 1
  • 셸 배포 · 입력 요청셸
    [sudo] password for ktadev:
1입력칸에 쓰고 Enter나 보내기를 누르면 그 글과 Enter를 터미널에 칩니다. 비밀번호 물음이면 글자를 가립니다. loom은 이 글을 저장하지 않습니다. 「터미널에서 답하기」도 그대로 남습니다.
