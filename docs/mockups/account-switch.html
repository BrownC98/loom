계정 전환: 실행 중인 노드도 옮기기와 자동 전환

사람 지시: 「loom에서 계정 전환시 각 터미널 노드에도 자동으로 계정 전환되는 기능」, 「현재 계정을 다 쓰면 자동으로 다른 할당량 남은 계정으로 옮겨지는 기능」, 「자동전환도 옵션에서 활성화 스위치 달아놔」. 바뀌는 구역은 세 곳이다: 계정을 바꿀 때 뜨는 확인 창, 설정 › 계정 탭 맨 위의 스위치, 하단 상태 줄의 알림. 점선이 새로 생기는 곳이다.

  • 그 공급자의 실행 중인 노드가 없으면 창을 띄우지 않고 지금처럼 바로 바꾼다.
  • [모두 바꾸기]: 노드마다 프로세스를 새 계정으로 다시 띄우고 같은 세션을 잇는다(Claude --resume, Codex resume). 노드 이름·카드·부모·자식·메일함은 그대로다. 일하는 노드는 지금 턴이 끝난 뒤 바꾼다.
  • [새 노드만]: 지금처럼 새 노드만 새 계정으로 뜬다. Esc와 바깥 클릭은 취소다(계정을 바꾸지 않는다).
  • OpenCode 2와 터미널만 있는 노드는 목록에 넣지 않는다.

② 설정 › 계정: 자동 전환 스위치 기본값 꺼짐

쓰는 계정의 5시간 또는 주간 사용량이 95%를 넘거나 노드가 한도 오류로 멈추면, 같은 공급자에서 남은 양이 가장 많은 계정으로 바꿉니다. 실행 중인 노드도 옮기고, 한도로 멈춘 노드는 이어서 일합니다. 사용량을 읽지 못한 계정은 고르지 않습니다.
