맥 앱 상단바: Windows와 같은 줄을 그대로 쓸지, 맥 창 버튼을 쓸지 정한다

사람 지시: 「애플 실리콘, 디벨롭 계정 없음, 윈도우, 웹, 맥 버전의 코드 차이를 최소화 하는 방향으로 진행」. 바뀌는 곳은 맥 앱 창의 맨 위 줄뿐이다. Windows 앱과 브라우저 화면은 바뀌지 않는다. 점선이 Windows와 다른 곳이다.

  • 맥에서도 OS 제목 줄을 끄고 Windows와 같은 36px 줄을 그린다. 왼쪽 loom 마크, 오른쪽 최소화·최대화·닫기다.
  • 화면 코드와 앱 코드가 Windows와 같다. 맥만 다른 분기가 없다.
  • 맥 사용자가 기대하는 왼쪽 빨강·노랑·초록 버튼은 없다. 닫기는 앱을 끝낸다(지금 Windows와 같다).
  • 화면 맨 위 맥 메뉴 막대(loom·편집·창)는 Tauri 기본 메뉴로 그대로 있다. ⌘C·⌘V·⌘Q가 된다.
