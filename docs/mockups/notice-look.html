알림 표시 통일: 종류마다 이름·색·아이콘·번호·[확인] 자리를 한 표로

사람 지시: 「알림 ui가 파편화 되어있는지 랩터3 로 검토해」, 「완료 칩은 알림 상태를 표시하라는게 의도였음 (완료 알림 발송하면 알림 칩이 뜨고, 질문 올리면 질문 칩이 뜨도록)」. 점검 결과, 같은 알림이 화면마다 다른 이름·번호·단추 자리로 보인다. 아래 표 하나를 모든 화면(PC 알약, 목록 줄, 폰 띠, 노드 칩, 그래프 카드, 미니맵, 시스템 알림)에 똑같이 쓴다. 점선이 바뀌는 곳이다.

  • 노랑 알림이 초록 알림보다 먼저다. 한 자리에 하나만 보이면 맨 앞 알림을 보인다.
  • 노드 하나를 세는 수(알약, 칩, 카드, 목록 노드 머리)는 맨 앞 알림과 같은 색 알림만 센다. 여러 노드를 합친 수(사이드바·폰의 [알림] 탭)만 모든 알림을 세고 분홍이다.
  • 번호는 사람이 터미널에 「Q12: A」로 답할 수 있는 질문에만 붙인다.
  • 알림 줄은 어디서나 「아이콘 이름 수 번호 노드: 글」이다. 글이 없는 알림(승인 창 등)은 「노드」만 보인다. 지금 PC 알약은 이름을 한 번 더 쓴다(「배포: 승인 요청」).
