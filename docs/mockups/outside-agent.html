채팅방: 외부 에이전트가 쓴 줄을 사람의 줄과 나누어 보이기

사람 결정(R428 D1 B, D2 A, D3 A): “mcp 말고 cli 로 할 수 없나”. Aside 같은 외부 에이전트는 제 셸 도구에서 loom room send <노드> "<말>" --from Aside로 노드의 채팅방에 쓰고, loom room read <노드> --wait 60으로 답을 받습니다. 그 말은 채팅방에 「외부 에이전트 · Aside」의 줄로 보이고, 노드는 사람의 지시가 아니라 외부 에이전트의 말로 받습니다. 빨간 상자가 바뀌는 곳이고, 점선 상자는 새로 생기는 곳입니다.

Aside: loom room send→채팅방에 「외부 에이전트 · Aside」 줄→노드가 메모로 받음(읽음)→노드: loom answer로 방에 답함→Aside: loom room read --wait로 답을 받음
