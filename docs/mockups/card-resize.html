그래프: 터미널 카드 크기를 마우스로 조정

사람 지시: 「현재 터미널 노드 크기를 디폴트로하되, 마우스로 노드 터미널 크기를 자유롭게 조정할 수 있게 해줘, 크기 초기화 버튼도 추가할 것」. 그림은 실제 크기의 60%다. 점선이 바뀌는 곳이다.

  • 손잡이는 그리지 않는다. 마우스가 카드 테두리에 오면 커서만 바뀐다: 오른쪽 변은 ↔, 아래 변은 ↕, 오른쪽 아래 모서리는 ↘. 거기서 끌면 크기가 바뀐다.
  • 빗금 띠는 설명용이다. 화면에는 없다. 감지 폭은 테두리 안팎 3px씩, 모두 6px다. 모서리는 12×12px다.
  • 머리의 다른 곳을 끌면 지금처럼 카드를 옮긴다. 터미널 안은 지금처럼 글자를 고른다.
  • 기본 크기 카드의 머리에는 지금과 같은 버튼(확대, 삭제)만 있다.
