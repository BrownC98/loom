응답할 곳: 총괄 · loom 총괄연 담당: 총괄 · loom 총괄v1 · 2026-10-21

그래프: 부모·자식이 아닌 노드 사이 메시지 표시

사람 지시: 「loom에서 모든 터미널은 다른 모든 터미널에 메시지를 보낼 수 있도록 해」. 이제 다른 나무·다른 저장소의 노드에도 메시지가 갑니다. 두 노드 사이에는 간선이 없어 지금 화면은 아무것도 보이지 않습니다. 바뀌는 구역은 그래프 위 메시지 표시뿐입니다. 점선(노란색)이 새로 그리는 것입니다. 그림의 점선은 실제처럼 움직입니다.

① 지금 전체메시지 → 화면워커, 표시 없음

  • 부모·자식 간선의 메시지는 지금처럼 3초 동안 점선으로 흐르고 「2 메시지 → 총괄」을 적습니다. 이것은 바꾸지 않습니다.

② 한쪽으로 보냄

A. 잠깐 보이는 선 권장

  • 두 카드의 위 변을 잇는 점선 곡선을 3초 동안 그립니다. 곡선은 위로 휘어 사이 카드를 되도록 지나지 않습니다. 간선 강조와 같은 모양·시간이고, 받는 쪽으로 흐릅니다.
  • 라벨은 간선과 같은 「1 메시지 → 화면워커」입니다. 3초 안에 다시 오면 수가 늘고 시간이 다시 시작합니다.
  • 선은 다른 카드·상자 위에 그립니다(강조한 간선과 같은 층). 3초 뒤 사라지고 남지 않습니다.
  • 한쪽 카드가 화면 밖이면 선은 화면 가장자리까지만 보입니다. 시점은 옮기지 않습니다.

B. 받는 카드만 강조

  • 선 없이 받는 카드 테두리를 3초 동안 강조하고 위에 「1 메시지 ← 전체메시지」를 적습니다.
  • 보낸 카드가 어디 있는지는 보이지 않습니다. 이름이 같은 노드가 여럿이면 구별하기 어렵습니다.

③ 3초 안에 서로 보냄 (A안)

  • 간선과 같은 규칙입니다. 라벨에 두 쪽을 「 · 」로 잇고, 점선은 흐르지 않습니다.
  • 움직임 줄이기 설정이면 점선이 멈추고 라벨만 남습니다.
