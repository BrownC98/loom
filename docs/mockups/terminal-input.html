터미널 표준 입력 창

사람 지시: 「포커싱된 터미널이 있으면 화면 하단에 입력 ui 가 플로팅되어 나타나 입력하고, 이미지, 파일경로도 받을 수 있도록 하는 거임, 이미지의 경우 썸네일과 크게보기, 리스트에서 제거도 포함」. 입력 창은 보낼 때 글과 경로를 터미널에 붙여넣는다. 그래서 에이전트의 / 명령, 자동 완성, 기록이 그대로 된다. 터미널에 바로 치는 입력도 그대로다. 데스크톱 앱, 브라우저, 폰 앱에서 같다.

D1입력 창은 언제 보이는가

A터미널이 있는 노드를 고르면 늘 보인다권장지금: 입력 창 없음 → 바뀐 뒤: 카드를 누르면 아래에 뜸 · 그래프 아래쪽 약 90px을 가림 · 되돌리기: 설정 › 그래프에서 끄기
B단축키나 버튼을 눌렀을 때만 보인다화면을 가리지 않음 · 사람이 매번 열어야 함
C지금 그대로(입력 창 없음)그림은 터미널에 붙여넣기, 파일은 끌어다 놓기만 됨

  • 알림 알약처럼 설정 › 그래프에 끄기 칸을 둔다. 끄면 지금 화면과 같다.

D3Enter는 무엇을 하는가

AEnter는 붙여넣고 Enter까지 친다. Shift+Enter는 줄바꿈권장데스크톱: 한 번에 보냄 · 폰: 키보드 Enter는 줄바꿈, 보내기 버튼으로 보냄 · 되돌리기: B로 바꾸기 쉬움
BEnter는 붙여넣기만 한다. 사람이 터미널에서 Enter를 친다보내기 전에 터미널에서 한 번 더 볼 수 있음 · 매번 두 번 누름
  • 알림 답 칸이 이미 Enter 보내기, Shift+Enter 줄바꿈이다(Inbox.tsx AnswerForm).
  • 폰 입력 칸은 지금 한 줄이라 Enter가 보내기다. 여러 줄이 되면 Enter를 줄바꿈으로 쓴다.
