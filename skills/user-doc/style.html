Claude

시스템 기본 계정은 셸에서 claude auth login로 로그인하거나 ‘계정 추가’를 클릭하십시오.
  • [로그인]: 지금 [계정 추가]와 같은 로그인 창(⑤)에서 claude auth login·codex login을 띄운다. 로그인 폴더 변수는 넣지 않는다(시스템 기본 폴더).
  • 셸 명령을 알리는 안내 줄(취소선)은 지운다. 버튼이 같은 일을 한다.

③ CLI를 설치하지 않음 Windows: codex가 PATH에 없음

Codex

시스템 기본사용 중설치 안 됨~/.codex `codex`이(가) 이 컴퓨터에 없습니다. 설치하고 PATH에 넣습니다.
  • [계정 추가]는 꺼진다. 마우스를 올리면 이유를 보인다. 지금은 눌러야 알 수 없는 오류가 났다.
  • 다른 경로로 CLI가 없어졌을 때 [계정 추가]·[로그인]을 누르면 오류 줄에 「Codex: `codex` 명령을 찾지 못했습니다. 설치한 뒤 설정에서 ‘다시 찾기’를 클릭하십시오.」를 보인다(노드 만들기와 같은 문구).
  • CLI가 있으면 로그인 명령도 노드처럼 찾는다(npm codex.cmd를 Windows에서 바로 띄움).
