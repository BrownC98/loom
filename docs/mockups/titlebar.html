Windows 앱 상단바: 기본 제목 줄을 loom이 그린 줄로 바꾼다

사람 지시: 「orca 처럼 상단 앱바를 기본 ui 말고 세련되게 할 수 없나」. 바뀌는 곳은 Windows 앱 창의 맨 위 줄뿐이다. 점선이 바뀌는 곳이다. 브라우저에서 연 화면(127.0.0.1)은 바뀌지 않는다.

  • 왼쪽: loom 마크(앱 아이콘의 짜임 무늬)만 둔다. 이름 「loom」은 바로 아래 사이드바 머리에 있고, 판 번호는 상태 줄에 있다.
  • 빗금 구역: 끌면 창이 옮겨진다. 두 번 누르면 최대화·이전 크기가 바뀐다. 빗금은 목업 표시이며 실제 화면에는 없다.
  • 오른쪽: 최소화·최대화·닫기(각 46×36px, Windows 기본 크기). 색은 화면 토큰(--panel·--ink-3)을 따른다.
  • 창 가장자리를 끌어 크기를 바꾸는 동작과 창 그림자는 지금과 같다.
