앱 질문 띠 색

사람 지시: "앱 질문띠가 적절한 알림 색이 아님 완료도 노란색으로 나옴". 띠의 색과 그림이 맨 앞 대기의 종류를 따른다. 점선이 바뀌는 곳이다.

① 질문 지금과 같음

shell-1
질문3Q12어느 쪽으로 할까요? (A: … / B: …)

② 완료 초록, 체크

shell-1
완료Q13폰 노드 목록을 터치용으로 바꿨습니다.
  • 질문과 완료가 섞이면 맨 앞(이 노드의 질문 → 가장 오래된 대기) 종류의 색이다. 숫자는 모든 대기 수다.
  • 펼친 판 안의 칸은 알림 탭과 같은 색이다(질문 노랑, 완료 초록).
