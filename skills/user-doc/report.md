# Reports

The common rules (one file, fixed parts, display) are in [SKILL.md](SKILL.md).

- Only the fixed parts in [SKILL.md "Form"](SKILL.md#form) are required: `<title>`, the head line (document ID, `응답할 곳`, version), the light default with the `.theme-toggle` button. loom's document page adds the HTML download button.
- All else is free: style tokens, fonts, layout, section order, headings, diagrams, tables. You can start from [style.html](style.html) or write your own `<style>`.
- Decision boxes are optional. If you use them, follow [SKILL.md "Decisions and IDs"](SKILL.md#decisions-and-ids): the document page makes their options answerable.
- Research, design and check records go in reports, not in mockups. Workflow analysis and design documents use [workflow-map](workflow-map/rules.md).
