노드 카드의 상태 칩과 상태 줄

사람 질문: 「사용자 경험을 향상시키기 위해서는 각 에이전트의 어떤 상태들을 보여줘야 할까?」 원칙: 사람은 결정만 합니다. 그래서 사람이 할 일이 있는 노드를 가장 먼저 보이고, loom이 혼자 하는 일은 조용히 둡니다. 지금 카드는 쉬는 노드가 무엇을 기다리는지 보이지 않습니다. 이 목업은 카드마다 칩 하나와 줄 하나를 둡니다. 데몬이 이미 가진 사실로 정하므로 토큰을 쓰지 않습니다.

  1. 카드의 칩 색으로 사람 일·문제를 먼저 봄
  2. 아래 줄에서 무엇을 기다리는지와 시간을 봄
  3. 칩을 눌러 자세한 사실을 봄

D1시간과 자세한 사실은 어디에 보이는가

A칩은 상태 이름만, 사실과 시간은 카드 아래 줄권장지금: 칩 없음(일함·쉼은 보이지 않음) → 바뀐 뒤: 머리 「검토 대기」, 아래 줄 「리뷰어 2명 중 1명 판정 · 7분」 · 비용: 표준 카드에 줄 하나(16px) · 되돌리기: 줄만 숨김
B한 칩에 모두: 「쉼 · 검토 대기 · 12분」줄을 더하지 않음 · 머리가 좁아 이름이 잘림 · 시간이 바뀔 때마다 칩 폭이 바뀜
  • 카드 머리에는 이미 이름, 에이전트, 모델, 단추 셋이 있습니다.
  • 표준 카드 아래 줄은 지금도 「꺼짐」 글에 씁니다. 같은 자리를 늘 씁니다.
  • 「쉼」은 대기 사유가 이미 말합니다. 칩에서 뺍니다.

D2칩 색은 몇 가지인가

A다섯 가지: 사람 노랑(지금 그대로), 문제 빨강, 일함 파랑, 대기 회색, 결과 초록권장지금: 노랑·빨강만 칩 → 바뀐 뒤: 모든 카드에 칩 · 비용: 지금 토큰만 씀(--run, --ok) · 되돌리기: 색 토큰 하나
B세 가지: 노랑, 빨강, 나머지 모두 회색더 조용함 · 일하는 노드와 기다리는 노드를 글로만 가림
  • 노랑과 빨강만 강한 색이라 사람 일과 문제가 먼저 보입니다. 파랑·초록은 점과 글자에만 씁니다.
  • 문제 카드는 빨간 테두리를 더합니다. 노란 테두리(질문)와 겹치면 노랑이 이깁니다.

D3「멈춤 의심」을 받은편지함에도 알리는가

A칩은 곧바로, 받은편지함은 loom의 30분 깨우기가 듣지 않았을 때만권장지금: 30분 뒤 loom이 한 번 깨우고, 다시 멈추면 아무도 모름 → 바뀐 뒤: 그때 받은편지함에 「api: 멈춤」 한 줄 · 비용: 알림 종류 하나 · 되돌리기: 알림만 끔
B칩만 보임알림 없음 · 다시 멈춘 노드는 사람이 그래프를 볼 때만 앎
C칩이 뜰 때 곧바로 받은편지함에도턴이 막 끝난 짧은 틈에도 알림이 옴 · 대부분 loom이 30분에 혼자 고침
  • 감시견은 깨우기를 한 번만 보냅니다. 마지막 메시지가 그 깨우기면 다시 깨우지 않습니다(src/graph/watchdog.rs). 그 뒤는 사람만 풀 수 있습니다.
  • 첫 30분은 loom이 혼자 풀므로 사람 일이 아닙니다.

D4잠든 카드에 「깨우기」 단추를 두는가

A두지 않음: 아래 줄에 「메시지를 보내면 깨어납니다」권장지금: 잠든 노드는 메시지가 오면 다시 뜸 → 바뀐 뒤: 같음, 글로 알림 · 비용 없음 · 되돌리기: 단추를 나중에 더함
B흐린 카드에 「깨우기」 단추할 말 없이 띄운 노드는 다시 쉬고 잠듦 · 새 API 하나
  • 잠든 노드는 할 일이 오면 데몬이 이미 깨웁니다(ProcessState::Asleep).
  • 할 일 없이 깨우면 토큰만 씁니다.

D5자세히 창에 토큰·메모리도 보이는가

A보이지 않음: 기다리는 것과 최근 상태만권장지금: 자세히 창 없음 → 바뀐 뒤: 칩을 누르면 ③ · 비용: 지금 있는 사실과 이벤트 기록만 씀 · 되돌리기: 창을 빼면 칩만 남음
B토큰·메모리 줄을 더함데몬에 지금 노드별 토큰·메모리 값이 없음 · 에이전트마다 새로 모아야 함 · 그 값으로 사람이 정할 일이 없음
  • 사람이 이 창에서 정할 것은 「기다려도 되는가」입니다. 기다리는 것 목록이 그 답을 줍니다.
  • 토큰·메모리는 사람이 고를 일이 생길 때 더합니다.
