서비스 이름과 앱 아이콘 시안

이름 후보 6개(지금 이름 loom 포함), 아이콘 4개, 이름을 바꿀 때 드는 비용을 보인다. 마지막 「결정할 것」 표에서 고른다. 이 페이지는 목업이다. 제품 코드는 바꾸지 않았다.

1. 이름 후보

CLI 이름은 사람과 에이전트가 <이름> spawn …처럼 매번 친다. 짧을수록 좋다. 충돌 조사는 2026-10-20에 직접 했다. 출처와 방법은 표 아래에 있다.

이름뜻 · 맞는 이유읽기CLIcrates.ionpmwingetGitHub 별 상위개발 도구 웹 검색판정
loom현재베틀 날실·씨실을 엮는 베틀. 에이전트 여럿을 한 그래프로 엮는다. 룸 / loom loom spawn (4자) loom 7,299만 내려받기 (tokio-rs 동시성 테스트) loom 있음 (생성기 도구) Loom.Loom(Atlassian)과 Teradata.Loom이 별칭 loom을 쓴다 CapSoftware/Cap ★23k(Loom 대체품), tokio-rs/loom ★2.8k Atlassian Loom(loom.com 영상 메시지)이 검색 첫 화면을 차지한다. 등록 상표 여부는 가설: 확인하지 않음 충돌 큼
Kumi권장組 · 구미 일본어 組(조·팀)와 組紐(쿠미히모, 끈 땋기). 팀과 엮기를 한 낱말에 담는다. 짧고 소리가 쉽다. 쿠미 / KOO-mee kumi spawn (4자) 없음 kumi 있음 (작은 스타일 생성기) 없음 별 200 이하. 관계없는 저장소뿐(kumiko 만화 자르기 등) 같은 이름의 개발 도구를 찾지 못했다. kumicare/kumi-tools(가족 비서 봇)만 있다 충돌 적음
Clotho클로토 그리스 신화에서 생명의 실을 잣는 운명의 여신. 노드(실)를 뽑아 내는 도구. 클로토 / KLOH-thoh clotho spawn (6자) clotho 8천 (AWS 서명 검증) clotho 있음 (DOM 빌더) 없음 별 200 이하. 관계없음 개발 도구 없음. 합성생물학 플랫폼, clotho.ai(법과학), clotho.one(이미지 생성) 중간
Bobbin보빈 · 실패 실을 감는 실패. 일을 감아 두었다가 풀어 준다. 친근한 소리. 보빈 / BOB-in bobbin spawn (6자) bobbin 예약만 됨 bobbin 있음 (“thread-like worker processes”, 뜻이 가깝다) 없음 radiatoryang/bobbin ★194, bobbin-rs(임베디드, 관리 중단) scbrown/skein 에이전트 묶음에 “bobbin” 부품이 있다. bobbin.now(Threads 앱) 중간
Weft씨실 베틀의 씨실. 지금 비유를 그대로 둔다. 웨프트 / weft weft spawn (4자) weft 3,724 (HTML 템플릿) weft 있음 (Google 글꼴) 없음 WeaveMindAI/weft ★2k (AI 오케스트레이션 언어) 같은 분야 셋: WeaveMind Weft, Weft CLI(brew install weft, 에이전트 CLI), letsweft.com(에이전트 작업 판) 충돌 큼
Skein실타래 실타래, 그리고 V자로 나는 기러기 떼. 팀 비유가 좋다. 스케인 / skayn skein spawn (5자) skein 41만 (해시 함수) skein 있음 (암호화) 없음 rust-adventure/skein ★328 에이전트 도구가 7개 넘는다. rambaarde/skein은 “저장소별로 묶은 에이전트 보기”로 loom과 거의 같다. getskein.ai(상용) 충돌 큼
  • 발견: 직물 낱말(weft, skein, heddle)은 2026년 AI 에이전트 도구가 이미 많이 쓴다. heddle도 에이전트 터미널·오케스트레이터가 셋 이상 있어 표에서 뺐다. 그래서 직물 비유를 바로 쓰지 않는 Kumi를 권장한다.
  • crates.io: curl https://crates.io/api/v1/crates/<이름>. npm: npm view <이름>. GitHub: gh search repos <이름> --sort stars -L 3.
  • winget: winget 공식 색인(cdn.winget.microsoft.com/cache/source2.msix의 index.db)에서 id·이름·별칭·명령을 찾았다. 우리 BrownC98.loom은 아직 이 색인에 없다. 그래서 winget id는 지금 바꾸면 비용이 없다.
  • 웹 검색: “<이름> AI agent developer tool”로 찾았다. 상표 등록(KIPRIS, USPTO)은 찾지 않았다. 모든 후보의 상표 상태는 가설이다.
  • Kumi의 약점: 한국어 사용자에게 뜻이 바로 보이지 않는다. 일본어 낱말이다.

2. 아이콘 시안

각 시안을 256·32·16 px로, 밝은 바탕과 어두운 바탕에 보인다. 오른쪽 아래 확대 칸은 16 px로 그린 화소를 6배로 키운 것이다. 이 칸에서 모양이 보이는지 본다.

A. 짜임 다듬기 지금 아이콘 바탕

16 px: 띠 넷이 바람개비처럼 엇갈린다. 틈은 흐려진다. 지금 3×3은 16 px에서 흰 덩어리가 된다.

지금 파란색(#2E5BD6)을 둔다. 3×3 짜임을 2×2 굵은 띠로 줄였다. 짝 이름: loom, Weft.

B. 노드 그래프 새 시안

16 px: 파란 부모 하나와 흰 자식 둘이 보인다. 선은 흐려진다.

제품 화면 그대로다: 부모 카드와 자식 카드를 간선이 잇는다. 이름에 묶이지 않아 어느 이름과도 쓴다.

C. 땋은 끈 새 시안

16 px: 두 색 끈의 S자가 보인다. 엇갈림 틈은 흐려진다.

組紐(쿠미히모) 두 끈이 엇갈려 올라간다. 에이전트 둘이 주고받는 모양이다. 짝 이름: Kumi.

D. 실과 노드 새 시안

16 px: 노란 점 둘과 물결이 보인다.

실 하나가 노드를 차례로 꿴다. 메시지가 노드 사이를 건너가는 모양이다. 짝 이름: Clotho, Bobbin.

Windows 작업 표시줄 (24 px, 100% 배율)

회색 칸은 다른 앱이다. 밑줄 있는 칸이 실행 중인 시안이다.

왼쪽부터 A·B·C·D. B는 이름과 관계없이 쓸 수 있어 이름을 바꾸지 않아도 고를 수 있다.

3. 이름을 바꿀 때 바뀌는 곳

저장소에서 loom을 쓰는 곳은 48개 파일, 397줄이다(git grep -i loom, 목업 제외). 아래 표에서 「둔다」는 낮은 비용 안(표시 이름만 바꾸기)에서 바꾸지 않는 곳이다.

곳지금 값바꾸면 생기는 일낮은 비용 안
앱 표시 이름, 창 제목, README·docs 제목productName: "loom"문구만 바뀐다. 위험 없음.바꾼다

GitHub 저장소 이름BrownC98/loomGitHub가 옛 주소를 새 주소로 넘긴다. 업데이트 확인 주소는 확인해야 한다(가설: 넘김이 릴리스 내려받기에도 맞다).바꾼다

데이터 폴더~/.loom (DB, 계정)옮기는 코드가 필요하다. 빠뜨리면 노드·계정 기록이 사라진 것처럼 보인다.둔다

  • 권장: 사용자에게 보이는 곳(표시 이름, 아이콘, 저장소, winget id, README)만 Kumi로 바꾼다. 안쪽 이름(CLI loom, LOOM_*, ~/.loom, Tauri id)은 둔다. 충돌이 생기는 곳은 검색·winget·상표이고, 이것은 모두 보이는 곳이다.
  • 낮은 비용 안의 단점: 제품 이름(Kumi)과 명령(loom)이 다르다. 나중에 CLI도 바꾸려면 별도 작업으로 한 번에 바꾼다(스킬·브리프·환경 변수를 함께).
  • 이름을 바꾸지 않아도 아이콘은 따로 고를 수 있다.
