1. 저장소 추가와 트리에서 저장소 바꾸기

  • 사이드바 「저장소」 머리의 [+]가 저장소 추가 창을 연다. Orca 「프로젝트」 머리의 [+]와 같은 자리다.
  • 트리는 더한 저장소를 모두 보인다: 저장소 > 워크트리 묶음 > 노드. 저장소 줄을 누르면 그래프가 그 저장소로 바뀐다. 고른 저장소는 이 브라우저에 남긴다.
  • 경로는 데몬이 보는 파일 시스템의 경로다. 없는 폴더, git 저장소가 아닌 폴더는 거절하고 이유를 보인다. 같은 저장소의 다른 워크트리를 적으면 원래 체크아웃 한 줄로 더한다.

2. 새 워크트리 창

  • 그래프 도구 줄의 [새 워크트리]가 연다. 입력은 브랜치 이름과 기준 브랜치 둘이다(design.md 「그래프와 화면」).
  • 폴더는 Orca 「워크스페이스 중첩」과 같다: <워크스페이스 폴더>/<저장소 이름>/<브랜치 마지막 마디>. 만들 폴더를 창 아래에 미리 보인다.
  • 기준 브랜치의 처음 값은 원래 체크아웃의 브랜치다. 목록은 로컬 브랜치다.

3. 그래프의 두 묶음과 [워크트리 닫기]

  • 묶음은 git worktree list 순서로 나란히 놓는다. 첫째가 원래 체크아웃이다. 묶음마다 [정렬] [새 노드]가 있다.
  • 추가한 워크트리 묶음 머리에만 [워크트리 닫기]가 있다. 누르면 확인 창이 연다. 닫으면 폴더를 지우고 브랜치는 남긴다. 그 묶음의 끝난 노드도 지운다.
  • 거절: 커밋하지 않은 변경이 있거나 running 노드가 있으면 이유를 창에 보이고 닫지 않는다.
  • loom spawn --worktree <브랜치>로 만든 자식은 새 묶음에 뜨고, 부모와 간선으로 잇는다.

4. 설정: 워크스페이스 폴더

  • 설정 창에 「워크스페이스」 탭(#settings/workspace)을 더한다. Orca는 「일반 > 워크스페이스」에 둔다. loom에는 「일반」 탭이 없어 같은 이름의 탭으로 둔다.
  • 글 입력 하나다. 처음 값은 ~/loom/workspaces다(Orca 기본값 ~/orca/workspaces와 같은 모양). 입력에서 나가거나 Enter를 누르면 저장한다. 상대 경로는 거절한다.
  • 넣지 않은 Orca 기능: [찾아보기](브라우저는 데몬 기계의 폴더를 고르지 못한다), 「워크스페이스 중첩」 스위치(늘 중첩한다), 호스트별 재정의.
