폰 화면: 질문 답하기, 노드 목록, 터미널

사람 지시: "모바일에서의 ui/ux 설계 진행", "모바일은 orca처럼 컴퓨터의 작업을 통제할 수 있는 단말기 역할을 한다". 폰은 PC 데몬의 같은 웹 화면을 폰 폭(390px)으로 보인다(보고서 R13 정할 것 ①②의 권장안). 화면은 1단계(답·트리·터미널·멈추기)를 먼저 그렸다. 2단계 표시는 보고서 정할 것 ④·⑥에 달렸다. 점선은 아직 정하지 않은 결정에 달린 곳이다.

v3에서 바뀐 곳(사람 지시 "이부분 pc 판과 동일하게 다크 테마에 노란 테두리로"): ④ 터미널의 질문 배너가 데스크톱 질문 알약과 같은 모양이다. v2에서 바뀐 곳(사람 지시 "모바일 질문 ui 도 동일한 노란색 써야함, 그리고 앱에도 llm 사용량 표시 동일하기 나와야함"): 질문 보내기 단추가 질문 색(노란색)이다. 아래 탭 위에 데스크톱 상태 줄과 같은 사용량 줄이 있다. 누르면 ⑧ 사용량 판이 열린다. 질문 색과 사용량 줄은 설정 「색」에서 고른 색을 따른다. 폰 그래프는 1단계에 넣지 않는다(사람 결정 Q281).

① 이동 아래 탭 2개 + 터미널 전체 화면

  • 아래 탭은 [질문]과 [노드] 둘이다. 질문 수 배지가 [질문] 위에 뜬다. 터미널은 탭이 아니다. 노드를 고르면 전체 화면으로 열고, 위 왼쪽 [뒤로]나 폰의 뒤로 몸짓으로 앞 탭에 돌아간다.
  • 주소는 화면마다 다르다(#/inbox, #/nodes, #/node/12). 그래서 폰의 뒤로 몸짓과 알림의 링크가 맞는 화면을 연다.
  • 구현 계약(WIG): 입력 칸 글자 16px(iOS 확대 막기), 아래 탭·입력 막대는 env(safe-area-inset-bottom)만큼 띄움, 아래 판은 overscroll-behavior: contain, 단추는 touch-action: manipulation, theme-color는 바탕색, 폰에서는 자동 초점 없음.
  • 폭 640px 미만에서 이 배치가 된다. 그 이상은 지금 데스크톱 화면 그대로다. 그래프 캔버스·커밋 그래프·설정은 폰 배치에 없다(R13 6절 버린 부품).
