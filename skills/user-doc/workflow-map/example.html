실시예 분석 정보 구조 v0.1 · 2026-11-03

1차 목표(DEC-2026-1103-002): 공보를 식별해 실시예를 누락 없이 추출·분석하고, 안쪽 축 지도 위에서 빈 곳과 그 근거를 도출한다. 빈 곳의 가치 판단은 작업자 몫. 카드를 누르면 오른쪽에 속성·함수·JP7581782 실제 예시·실패 사례가 나온다.
