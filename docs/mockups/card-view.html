● 작업을 둘로 나눕니다.
  ⎿ claude-1: 로그인 화면
  ⎿ codex-1: 인증 API
  1. 심플 카드: 폭 260, 높이 132입니다. 로고·이름·지우기 버튼, 지금 하는 일(두 줄까지), 모델 · 추론 강도, 상태·읽지 않은 수·보관 수입니다. 모르는 값은 비웁니다(shell-1).
  2. 지금 하는 일: 새 LLM 호출 없이 하네스가 이미 만든 값을 씁니다. 끝난 노드는 보낸 요약, 도는 노드는 하네스가 정한 터미널 제목, 제목이 없으면 첫 지시입니다.
  3. 터미널: 심플 보기에서는 카드에 터미널이 없습니다. 카드를 누르면 그 노드의 터미널이 오른쪽 칸에만 열립니다.
  4. 보기 전환: 위 막대의 ‘심플 / 표준’은 그래프 전체를 바꿉니다. 설정 「UI」의 ‘카드 보기’와 같은 값입니다. 표준 보기는 지금 카드(머리와 80×24 터미널)입니다.
  5. 배치: 카드 줄 높이와 칸 폭, 묶음 크기는 잰 카드 크기로 정합니다. 묶음은 머리 글자와 버튼보다 좁지 않습니다(TERM-세션-만료).

  1. [정렬]: 그래프 전체를 정렬합니다. 끈 카드와 끈 묶음을 모두 제자리로 되돌립니다. 묶음 머리의 [정렬]은 지웁니다. 지금도 묶음의 [정렬]이 모든 카드를 되돌리므로 입구를 하나로 둡니다.
  2. 방향 메뉴: ‘아래로’, ‘오른쪽으로’, ‘위로’, ‘왼쪽으로’입니다. 고르면 바로 그 방향으로 정렬합니다. 버튼의 화살표가 지금 방향입니다. 방향 하나를 이 브라우저에 둡니다.
  3. 묶음 사이: 나무가 아래·위로 뻗으면 묶음을 가로로, 오른쪽·왼쪽으로 뻗으면 세로로 놓습니다. 틈은 32입니다. 순서는 왼쪽 목록의 워크트리 순서입니다.
