# loom 설계

2026-10-19 설계 인터뷰에서 정한 결정이다. 구현은 이 문서를 따른다. 결정을 바꾸면 이 문서를 같은 커밋에서 고친다.

- [목표](design/목표.md): loom이 무엇이고 무엇을 줄이려는지.
- [그래프와 화면](design/그래프와-화면.md): 그래프, 사이드바, 카드, 저장소와 워크트리 화면 규칙.
- [에이전트 실행](design/에이전트-실행.md): PTY 호스트, 에이전트 프로필, 내장 스킬, 계정, 설정.
- [메시징](design/메시징.md): 메시지 종류, 전달, 사람 응답 대기, 작업 폴더, 병합 관문.
- [저장](design/저장.md): SQLite 저장소와 그 규칙.
- [규모](design/규모.md): 터미널 스트림과 갱신의 크기 한도.
- [기술 스택](design/기술-스택.md): Rust 실행 파일, 데몬과 화면의 라이브러리.
- [데몬 하나](design/데몬-하나.md): 한 기계에 데몬 하나와 뷰어.
- [배포](design/배포.md): Linux 호스트 실행 파일과 배포 절차.
- [데스크톱 앱](design/데스크톱-앱.md): Windows·macOS 앱 창과 업데이트.
- [원격](design/원격.md): 폰 연결, 웹 앱, Android 앱.
- [레이어](design/레이어.md): 모듈 레이어와 의존 방향.
- [실측 근거](design/실측-근거.md): 에이전트 CLI에서 확인한 동작.
- [아직 확인하지 않은 것](design/아직-확인하지-않은-것.md): 확인하지 못한 경로와 이유.
- [후속](design/후속.md): 다음에 할 일.
