사람 응답 대기 알림

사람 지시: “에이전트가 사람에게 승인 또는 선택을 하게끔 하는 질문을 loom 시스템에서 표준화 하여, 사람이 응답하거나, 승인해야하는 부분이 생기면 알림이 발생하여 해당 알림 클릭하면 질문이 발생한 노드로 이동할 수 있게 해줘”. 점선이 바뀌는 곳이다. 답은 지금처럼 노드 터미널에 쓴다.

① 지금 화면 시험 데몬 v0.1.505

  • 노드가 사람을 기다려도 화면에 표시가 없다. 카드 터미널을 직접 열어야 안다.

✳ 5시간 34%v0.1.505
  • 상태 줄 오른쪽, 버전 옆에 [질문] 단추가 늘 있다. 기다리는 노드가 있으면 주황 숫자가 붙는다. 그래프 위를 가리지 않는다.
  • 사이드바: 기다리는 노드의 점이 주황 고리로 바뀐다.

✳ 5시간 34%v0.1.505
  • 기다리는 노드마다 한 줄: 노드 이름, 종류(질문·승인 요청), 질문 한 줄. 최근 것이 위다. 줄이 많으면 목록 안에서 스크롤한다.
  • 「질문」은 에이전트가 loom ask로 쓴 한 줄, 「승인 요청」은 CLI의 권한·승인 창이다.
  • 바깥을 클릭하거나 Esc를 누르면 닫힌다.

시스템 알림

켜면 브라우저가 알림 허용을 한 번 묻습니다.
loom 코디-화면 · 질문 목업 A·B 가운데 어느 쪽으로 할까요?
  • 기본은 꺼짐이다. 받은편지함이 늘 보이므로 시스템 알림은 더 원하는 사람만 켠다. 허용 요청도 이 체크를 켤 때만 나온다.
  • 켜 두면 창이 가려져 있을 때 시스템 알림(아래 검은 상자)을 띄운다. 클릭하면 loom 창이 앞으로 오고 ④가 된다.
