바뀌는 곳

위 그림은 바뀌는 구역만 그렸다. 커밋 그래프 글자는 시험 저장소에서 데몬 GET /api/commits가 실제로 돌려준 출력이다.

1. 그래프 위 도구 줄

  • 전 → 후: 저장소 이름·경로만 있다 → 오른쪽 끝에 [커밋 그래프]가 있다. 열린 동안 눌린 모양(코발트 테두리)이다.
  • 문제점: 에이전트가 만든 브랜치와 커밋을 보려면 터미널에서 git log를 쳐야 한다.
  • 개선 사항: 한 번 눌러 커밋 그래프 칸을 열고 닫는다.

2. 그래프 오른쪽 아래 미니맵

  • 전 → 후: 미니맵이 없다 → 200×150 미니맵이 있다. 묶음은 점선 테두리, 카드는 상태 색(running 코발트, done 초록, exited 빨강)이다. 지금 보이는 자리는 밝은 틀이고 나머지는 어둡다.
  • 문제점: 카드가 늘면 화면 밖 카드가 어디 있는지, 어느 카드가 끝났는지 알 수 없다.
  • 개선 사항: 미니맵의 한 점을 누르면 그 자리가 그래프 가운데로 온다. 밝은 틀을 끌면 그래프가 따라 움직인다.

3. 커밋 그래프 칸(오른쪽)

  • 전 → 후: 없다 → 520px 칸이 그래프 오른쪽에 붙는다. 그래프는 덮이지 않고 좁아진다.
  • 문제점: 워크트리 묶음이 어느 커밋에 있는지, 병합이 어떻게 이어졌는지 화면에서 볼 수 없다.
  • 개선 사항: 모든 브랜치와 병합 선을 git log --graph로 보인다. 워크트리가 체크아웃한 커밋 줄 끝에 반전 표시(「원래 체크아웃 main」, 「워크트리 feat/minimap」)가 붙는다. 표시 글은 묶음 머리의 종류·브랜치와 같다.
  • 상태: 처음 읽는 동안 「읽는 중…」 한 줄, 커밋이 없으면 「아직 커밋이 없다」, git이 실패하면 git 오류 문장을 빨간 글자로 보인다.

결정표

항목결정이유
그리는 방법(가) 데몬이 git log --graph --color=always --all 출력을 주고, 화면이 이미 쓰는 xterm.js로 그린다배치 코드가 없다. 병합 선과 색은 git이 그린다. (나) SVG 차선은 차선 배치와 그리기를 직접 써야 한다. 커밋을 누르는 요구가 없다. @gitgraph/js는 2022-04 뒤로 갱신이 없다(보관)
워크트리 표시데몬이 git worktree list --porcelain으로 워크트리마다 체크아웃한 커밋을 찾아 그 줄 끝에 붙인다git 장식(--decorate)은 워크트리 브랜치를 다른 브랜치와 구별하지 않는다. 분리된 HEAD 워크트리는 아예 보이지 않는다(git 2.43 실측)
표시 모양터미널 글자색·바탕색 반전(ANSI 7)새 색을 더하지 않는다. 굵은 초록 브랜치 이름과 겹치지 않는다
범위모든 브랜치(--all), stash 제외, 최근 커밋 1,000개. 긴 줄은 칸 끝에서 자른다stash는 모든 워크트리가 함께 쓰는 임시 커밋이다. 줄을 접으면 그래프 선이 끊긴다
여는 자리도구 줄 [커밋 그래프] → 그래프 오른쪽 칸(520px)팝오버·모달은 그래프와 미니맵을 가린다. 칸이면 둘 다 보인다. 열림 상태는 저장하지 않는다
갱신칸이 열린 동안 3초마다 다시 읽는다. 글자가 바뀔 때만 다시 그린다. 닫으면 읽지 않는다기존 이벤트(/api/events)는 커밋을 알리지 않는다. 사람이 터미널에서 한 커밋도 보여야 한다. 파일 감시는 새 의존성과 감시 코드가 든다
미니맵React Flow <MiniMap pannable>. 누르면 그 자리를 가운데로 옮긴다. 색은 styles.css 토큰이다이미 쓰는 라이브러리 부품이다. 끄기 설정과 휠 확대는 요구가 없어 두지 않는다
목업 파일이 파일을 따로 둔다. 승인 뒤 docs/design.md가 이 파일을 명세로 가리킨다다른 코디 셋이 main.html을 고치는 중이다
제품 범위docs/design.md 「기능은 셋만 둔다」에 커밋 그래프 보기(읽기 전용)를 더한다사람 지시. loom은 커밋·병합·체크아웃을 하지 않는다

점검 기록

  • 방향: 기준 화면 main.html의 토큰·버튼·카드 모양을 그대로 썼다. 새 색은 없다. 미니맵 가림막은 --bg를 color-mix로 섞었다.
  • impeccable detect 1회: 경고 3건, 모두 고치지 않았다. .app 아래 테두리 여백은 화면 틀 테두리다(main.html과 같은 오탐). 커밋 그래프 줄 높이 1.2는 노드 터미널(Terminal.tsx)과 같다. 더 벌리면 그래프 세로선이 끊긴다. 제목 단계 경고는 아래 설명 절(h2·h3)의 크기다. 제품 화면 글자 크기는 main.html과 같다.
  • WIG: 지켰다 — 아이콘만 있는 [닫기]에 aria-label, 아이콘에 aria-hidden, [커밋 그래프]에 aria-expanded·aria-controls, 커밋 글자에 translate="no", 긴 줄 자르기, 빈 상태·오류 상태, 읽는 중 글자 끝 「…」. 적용하지 않았다 — 미니맵 끌기의 키보드 대안(미니맵은 마우스용 지름길이다. 키보드는 Ctrl+Shift+방향키로 카드를 옮긴다), 열림 상태 URL(설정 창이 URL 해시를 쓴다. 칸은 한 번 눌러 다시 연다), 영어 문구 규칙(한국어 UI 예외).
