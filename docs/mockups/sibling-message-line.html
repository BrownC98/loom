그래프: 같은 레벨 노드 사이 메시지 선이 부모 카드에 가리지 않게 한다

사람 지시: 「같은 레벨 노드끼리 메시징 할 때, 연결선 표시가 부모 노드 뒤로 가려지는 문제가 있다. 그렇다고 해당 선이 부모노드위에 배치하는건 원치 않는데 이를 개선해줘」. v1 반려: 「이렇게 되면 각 선들이 서로 어디로 연결된건지 알아보기 힘든데 좋은 방법 없나」. 화면은 시험 데몬의 실제 캡처(그래프 부분)입니다: 아래로 배치, 계단 선, 한 부모 아래 형제 넷, 형제마다 자기 워크트리, 세 쌍이 동시에 메시지를 주고받고 그중 두 쌍(코디바→코디라, 코디마→코디사)이 엇갈립니다.

형제가 메시지를 보냄 → 보낸 카드 위에서 선이 나와 그 쌍의 줄까지 올라감 → 줄을 따라 받는 카드 위까지 감 → 화살표로 받는 카드에 들어감 (3초 뒤 사라짐)

① 지금: 곡선이 부모 카드 뒤로 들어가 가림

1형제 사이 곡선 셋이 위로 크게 휘어 부모 카드 뒤로 들어갑니다. 표 「6 msg → 코…」가 잘리고, 어느 선이 어느 카드로 가는지 보이지 않습니다.

② A안 · 권장: 쌍마다 따로 가는 줄, 색, 화살표, 「보낸 → 받은」 표

1메시지 쌍마다 줄 하나를 따로 씁니다. 짧은 쌍이 카드에 가깝고 긴 쌍이 위쪽 줄로 갑니다. 쌍마다 색이 다르고, 받는 카드 쪽 끝에 화살표가 있고, 표에 「코디바 → 코디라 · 2」처럼 보낸 쪽과 받는 쪽을 적습니다. 한 카드에 선이 둘이면 카드 위 다른 자리에서 나갑니다.

③ B안: A안과 같은 줄, 색은 하나

1줄·화살표·표는 A안과 같고 모두 검은 점선입니다. 두 선이 엇갈리는 곳(마2 위)에서는 어느 선이 이어지는지 표를 읽어야 압니다.

④ C안: 긴 선 없이 양 끝 표만

1보낸 카드 위에 「→ 코디마 · 3」, 받은 카드 위에 「코디라 → · 3」 표만 붙입니다. 선이 겹치지 않지만, 짝을 찾으려면 이름을 읽고 맞춰야 합니다.

승인할 것

정할 것선택지권장
형제 사이 메시지 선의 모양A: 쌍마다 따로 가는 줄 + 색 + 화살표 + 「보낸 → 받은」 표(②) / B: A와 같고 색 하나(③) / C: 선 없이 양 끝 표(④) / 지금 그대로(①)A
  • A를 권하는 이유 1: v1에서 지적한 문제(선이 한 줄에 겹침)를 없앱니다. 쌍마다 다른 줄을 써서 두 선이 같은 가로줄을 지나지 않습니다.
  • 이유 2: 색·화살표·표 세 가지로 보낸 쪽과 받는 쪽을 한눈에 봅니다. 색은 커밋 그래프가 이미 쓰는 줄 색 다섯 가지를 다시 씁니다.
  • 이유 3: 모든 선이 부모 카드와 형제 카드 사이 빈 줄 안에만 있습니다. 어느 카드에도 가리지 않고, 부모 카드 위에도 그리지 않습니다.
  • A의 한계: 같은 부모 아래 6쌍 넘게 동시에 메시지를 주고받으면 색이 다시 돌고 줄 사이가 좁아집니다(추정). 표의 이름으로 구분합니다. 되돌리기는 커밋 하나를 되돌리면 됩니다.
  • 부모가 다른 노드 사이 선은 지금 곡선 그대로입니다. 배치 방향이 오른쪽·위·왼쪽이어도 같은 규칙으로 부모 쪽 빈 줄을 씁니다.
