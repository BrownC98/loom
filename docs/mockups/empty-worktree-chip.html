노드가 없는 워크트리를 main 상자 안의 칩으로

사람 지시: 「작업용 워크트리가 공간 낭비가 심한것 같은데 저런 케이스는 main에 네스팅 하면 안됨?」 → 「노드가 없는 작업 워크트리를 따로 큰 상자로 그리지 않고, main 상자 안에 작은 칩 한 줄로 넣는다. 목업부터.」

워크트리를 만든다(노드 없음)→main 상자 안에 칩으로 보인다→칩의 [+]로 노드를 띄운다→보통 워크트리 상자로 돌아간다
