사람 질문: 「loom의 질의응답 ui/ux를 어떻게 더 매끄럽게 연결할 수 있을까? tui 구조를 탈피해야하나?」, 지시: 「시안들 목업부터 뽑아」(Q2559). 지금은 한 대화가 세 곳(카드 터미널, 알림 목록, 아래 입력 창)으로 나뉘고, 같은 완료 글이 터미널과 알림에 두 번 보입니다. 아래 네 안은 모두 같은 자료(사람 지시 → 질문 Q2559 답 → 완료 → 질문 Q2561)로 그렸습니다.
