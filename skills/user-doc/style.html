③ CLI를 설치하지 않음 Windows: codex가 PATH에 없음

Codex

시스템 기본사용 중설치 안 됨~/.codex `codex`이(가) 이 컴퓨터에 없습니다. 설치하고 PATH에 넣습니다.
  • [계정 추가]는 꺼집니다. 마우스를 올리면 이유를 보입니다. 지금은 눌러야 알 수 없는 오류가 났습니다.
  • 다른 경로로 CLI가 없어졌을 때 [계정 추가]·[로그인]을 누르면 오류 줄에 「Codex: `codex` 명령을 찾지 못했습니다. 설치한 뒤 설정에서 ‘다시 찾기’를 클릭하십시오.」를 보입니다(노드 만들기와 같은 문구).
  • CLI가 있으면 로그인 명령도 노드처럼 찾습니다(npm codex.cmd를 Windows에서 바로 띄움).
